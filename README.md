# 📦 StockControl – Sistema de Controle de Estoque

## 📌 Sobre o Projeto

O **StockControl** é um sistema desenvolvido para auxiliar empresas e pequenos negócios no gerenciamento eficiente de estoque. A aplicação permite controlar produtos, acompanhar movimentações de entrada e saída, monitorar níveis de estoque e manter informações organizadas em um único ambiente.

O objetivo do projeto é oferecer uma solução simples, intuitiva e eficiente para reduzir erros de controle e facilitar a gestão dos itens armazenados.

---

## 🎯 Objetivos

* Automatizar o controle de estoque;
* Facilitar o cadastro e gerenciamento de produtos;
* Registrar movimentações de entrada e saída;
* Permitir consultas rápidas de produtos;
* Alertar sobre níveis críticos de estoque;
* Melhorar a organização e o acompanhamento dos itens armazenados.

## 🚀 Funcionalidades

### 🔐 Autenticação

* Cadastro de usuários
* Login no sistema
* Controle de acesso

### 📦 Gerenciamento de Produtos

* Cadastro de produtos
* Edição de produtos
* Exclusão de produtos
* Listagem de produtos
* Consulta de informações detalhadas

### 📊 Controle de Estoque

* Registro de entrada de produtos
* Registro de saída de produtos
* Atualização automática de quantidades
* Histórico de movimentações

### 🔎 Pesquisa e Monitoramento

* Busca rápida de produtos
* Filtros de pesquisa
* Alerta de estoque baixo
* Visualização de produtos com baixa disponibilidade

## 🛠️ Metodologia Utilizada

O projeto segue princípios da metodologia ágil **Kanban**, permitindo o acompanhamento contínuo das atividades e o controle do fluxo de trabalho da equipe.

As tarefas são organizadas em colunas de status:

* A Fazer
* Em Andamento
* Concluído

Essa abordagem facilita a visualização do progresso e a distribuição equilibrada das atividades entre os integrantes.
